# Bhai Bhai Features

## Current implemented features

### Language syntax

- variable declarations using `dhoro`
- conditional blocks using `Bhai` and `Nahole`
- for-loops using `hobe`
- while-loops using `jotokhun`
- function declarations using `kaj`
- return statements using `ferot`
- break and continue using `tham` and `chol`

### Expressions

- numbers, strings, booleans, nulls
- arithmetic operators
- comparison operators
- logical operators
- unary `!` and `-`
- function calls
- arrays
- object-like literal structures in parser support

### Runtime

- lexical environment scope
- built-in output (`dekhaw`)
- built-ins for math and arrays
- assignment into existing variables
- recursive function calls

### Editor and UX

- browser IDE layout
- syntax highlighting
- autocomplete for keywords and built-ins
- token viewing panel
- AST viewing panel
- runtime output panel
- error panel
- file upload and download support

## Planned features

- better object property access
- proper string methods
- module imports
- standard library functions
- more robust error recovery
- REPL mode
- CLI runner
- test suite
- type system
- comments and docs examples

## Feature maturity

The project currently sits at the prototype stage. The language supports a useful subset of basics, but much of the advanced feature work is still planned rather than implemented.
