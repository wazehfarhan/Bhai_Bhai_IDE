Keep these close

Useful rules and current limits

Names

Variable and function names start with a letter or _, then may include numbers and _. Names like neo are valid identifiers, while keywords such as dhoro or Bhai stay reserved.

Output

Use dekhaw(value). Each call writes one line in Runtime.

Operators

+ - * / % ^, comparisons == != > < >= <=, and logical && || ! are available.

Current limits

Object properties and array indexing are not available yet. Use arrays with length, push, and pop.
